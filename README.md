# yogapp-audio

Legacy voice zips, story/skin/style packs, and pose packs for SynthYoga and SynthFit.
New voices publish zips to `yogapp-audio-{voiceId}` (see publish-voice-files.sh).

Published by `apps/yoga/scripts/publish-locale-audio.sh` in the yogapp repo.
`main` is force-pushed as a single commit on each publish.
